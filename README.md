# Arish Qadri — Portfolio

Personal portfolio for Arish Qadri — Social Media Manager, Video Editor & Cinematographer.

Built with Next.js 15 (App Router), TypeScript and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Content

All portfolio content (profile, work samples, services, skills, etc.) lives in a single
source of truth: `data/portfolio.ts`. Update that file to add new work samples, services,
or bio details — no need to touch component code.

## Structure

- `app/` — routes, layout, global styles
- `components/` — page sections and reusable UI (`components/ui`)
- `data/portfolio.ts` — all editable content
